Profile, school week, divisions & bell times, classes, timetable and data

Profile

School week & day types

Choose the bell schedule each day follows (e.g. Tuesday is different).

Two-week cycle

Use this if your timetable alternates between Week 1 and Week 2. Bell times are the same in both weeks; only the classes change.

Divisions & bell times

Each division has its own periods. Period names such as “P3” link the timetable to the bell times.

Classes / teaching groups

Name, usual room, course, and the division whose bells it follows. If a class meets somewhere else in some periods, type that room in the timetable cell below.

Weekly timetable

Choose the class you teach in each period. A dash means that period does not exist on that day. Changes save automatically.

Backup & data

All MathHub data is stored in this browser on this computer. Export a backup regularly, for example into this OneDrive folder, and import it to move to another computer or browser.
