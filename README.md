# MathHub

A planning dashboard for a mathematics teacher and subject lead (IB MYP 8–9, DP Mathematics AI SL and a school-designed non-DP course).

- **Dashboard**: today's classes, to-do list, 14-day agenda, curriculum coverage, review queue
- **Weekly planner**: timeline of Middle School and High School periods, two-week cycle, rooms, events, printing
- **Lesson plans**, **Courses & units**, **Worksheet generator** (random questions with answer keys)
- **Assessment hub** and **teacher submission form** for collecting formative and summative assessments
- **IB toolkit**: MYP grade calculator, rubric builder, command terms, IA milestone tracker

It is a static site with no server. Everything a user enters is stored only in their own browser (`localStorage`); nothing is sent anywhere. Use **Settings → Export backup** to keep a copy.
